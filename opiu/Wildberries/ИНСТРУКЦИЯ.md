# Финансовый отчёт Wildberries — инструкция

## 1. Подготовка (один раз)

Нужны Python 3.10+ и библиотека openpyxl. На этом компьютере оба уже установлены.
```
python -m pip install openpyxl
```

## 2. Токен API

1. Откройте кабинет продавца WB: **Профиль → Настройки → Доступ к API**.
2. Создайте **Персональный** или **Сервисный** токен и отметьте категорию **«Финансы»**. Режима «только чтение» достаточно.
   Для заказов и остатков в юнит-экономике сводного отчёта отметьте также **«Статистика»**, **«Аналитика»**, **«Маркетплейс»** и **«Контент»** (без них ОПиУ собирается, но заказов/остатков не будет).
3. Скопируйте токен сразу: потом его уже не показать.

## 3. Настройка кабинетов

Скопируйте шаблон `wb_accounts.example.json` в `wb_accounts.json`, откройте его в Блокноте и заполните (файл с токенами не попадает в git):

```json
{
  "period": { "from": "2025-09", "to": "2026-09" },
  "accounts": [
    { "name": "Магазин WB 1", "token": "eyJhbGciOi...", "enabled": true },
    { "name": "Магазин WB 2", "token": "eyJhbGciOi...", "enabled": true }
  ]
}
```

- **name** — название магазина, так будет называться лист в Excel.
- **token** — токен API с категорией «Финансы».
- **enabled** — `false` исключает магазин из отчёта.
- **period** — первый и последний месяц в формате `ГГГГ-ММ`. Данные в API доступны с 29.01.2024.

## 4. Запуск

1. Откройте папку `ОПиУ\Wildberries`, щёлкните по пустому месту с зажатым **Shift** и выберите **«Открыть окно PowerShell здесь»**.
2. Выполните:
   ```
   python wb_finance.py
   ```
3. В конце появится строка `Готово: wb_finance_2025-09_2026-09.xlsx`, рядом будет CSV со всеми строками отчёта.

**Сколько это длится.** WB разрешает **1 запрос в минуту** и отдаёт до 100 000 строк за запрос. Например, 160 000 строк за год загружаются примерно за 3 минуты: две части детализации и список отчётов для сверки. Во время пауз скрипт пишет `пауза … с` — так и должно быть.

Загруженные данные сохраняются в папку `cache`. Пересобрать Excel без обращения к WB можно командой `--from-cache`.

## Дополнительные параметры

| Что нужно | Команда |
|---|---|
| Другой период | `python wb_finance.py --from 2026-01 --to 2026-08` |
| Своё имя файла | `python wb_finance.py --out отчёт_WB.xlsx` |
| Без CSV со всеми строками | `python wb_finance.py --no-raw` |
| Пересобрать отчёт из прошлой загрузки, без запросов к WB | `python wb_finance.py --from-cache` |
| Проверить токен и формат данных (20 строк за 2 недели) | `python wb_finance.py --probe` |

## Как считаются статьи

Все цифры берутся из детализации еженедельных отчётов реализации. Месяц определяется по **дате операции** (`rrDate`).

| Статья | Поле отчёта WB |
|---|---|
| Продажи / Возвраты | цена продавца с учётом его скидки (`retailPriceWithDisc` × кол-во), для возвратов со знаком минус |
| Комиссия WB | цена продавца − к перечислению − эквайринг. Это кВВ с НДС и выдача на ПВЗ, совпадает с «Размером кВВ, %» |
| Эквайринг | `acquiringFee` |
| Логистика | `deliveryService`, по видам: к клиенту, от клиента, возвраты продавцу и т. д. |
| Хранение и приёмка | `paidStorage` + `paidAcceptance` |
| Штрафы | `penalty`, подпись — вид штрафа (сторно показаны отдельно) |
| Реклама и продвижение | удержания «WB Продвижение» и похожие, баллы и стоимость участия в программе лояльности |
| Прочие удержания | остальные удержания (например, утилизация) |
| Компенсации и доплаты | компенсации при возврате, коррекции продаж, корректировки ВВ |
| Авансы за услуги WB | аванс за «Баллы за отзывы» и возврат неиспользованного остатка — отдельно от расходов, потому что это движение денег, а не расход месяца |

**Справочно** (в итоги не входит):
- **Скидка WB покупателю (СПП).** Покупатель платит меньше цены продавца, разницу оплачивает WB.
- **Возмещение издержек по перевозке.** WB показывает эту колонку, но не вычитает её из выплаты.
- **Компенсация скидки по программе лояльности.** Она уже входит в «к перечислению».

**Итого к оплате продавцу** = к перечислению за товар − логистика − хранение − приёмка − штрафы − удержания + корректировка ВВ − баллы и стоимость программы лояльности.

Лист **«Сверка с WB»** сравнивает эту цифру с «Итого к оплате» из каждого еженедельного отчёта WB (метод `sales-reports/list`). Разница должна быть 0. Если появилась разница, значит WB добавил новое поле и формулу нужно обновить.

Лист **«Операции»** показывает суммы по каждому «Обоснованию для оплаты» и виду операции за месяц. Если статья выглядит странно, начинайте проверку с него.

Текущий месяц будет неполным: WB формирует еженедельный отчёт по понедельникам.

## Если что-то не так

| Сообщение | Что делать |
|---|---|
| `HTTP 401` | Токен неверный или истёк — создайте новый |
| `HTTP 403` | У токена нет категории «Финансы» или выбран не тот тип токена |
| `429` | Лимит запросов. Скрипт сам подождёт и повторит |
| `Нет соединения с API Wildberries` | Проверьте интернет и VPN |
| `PermissionError` при сохранении | Закройте Excel-файл и запустите снова |

**Безопасность:** токены в `wb_accounts.json` лежат открытым текстом. Не пересылайте этот файл.
