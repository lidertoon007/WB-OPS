# Как запустить финансовый отчёт Ozon

## 1. Подготовка (один раз)

1. Нужен Python 3.10 или новее. На этом компьютере уже стоит Python 3.14.
   Проверить: откройте PowerShell и выполните
   ```
   python --version
   ```
   Если команда не найдена, установите Python с https://www.python.org/downloads/ и при установке отметьте галочку **«Add python.exe to PATH»**.

2. Установите библиотеку для Excel (на этом компьютере уже установлена):
   ```
   python -m pip install openpyxl
   ```

## 2. Настройка кабинетов

Скопируйте шаблон `ozon_accounts.example.json` в `ozon_accounts.json`, откройте его в Блокноте и заполните. Файл `ozon_accounts.json` не попадает в git (см. `.gitignore`).

```json
{
  "period": { "from": "2025-09", "to": "2026-09" },
  "accounts": [
    { "name": "Магазин 1", "client_id": "1111111", "api_key": "ключ-1", "enabled": true },
    { "name": "Магазин 2", "client_id": "1234567", "api_key": "ключ-2", "enabled": true }
  ]
}
```

- **name** — название магазина. Так будет называться лист в Excel.
- **client_id** и **api_key** — берутся в личном кабинете Ozon: *Настройки → Seller API*. Ключу нужен доступ к разделу «Финансы»; для заказов и остатков в юнит-экономике сводного отчёта — ещё к отправлениям (FBO/FBS) и товарам (роль «Admin read only» покрывает всё).
  С 03.09.2026 ключи Ozon действуют **3 месяца**. Скрипт при каждом запуске с API узнаёт дату окончания (метод `/v1/roles`) и пишет её в консоль и на лист «Контроль» сводного отчёта; за 14 дней до окончания там появится статус «ПЕРЕВЫПУСТИТЬ КЛЮЧ». Перевыпустите ключ в ЛК и замените `api_key`.
- **enabled** — `true` означает, что кабинет попадёт в отчёт, `false` — что будет пропущен.
- **period** — первый и последний месяц в формате `ГГГГ-ММ`.
- Между блоками магазинов ставится запятая, после последнего блока запятой нет.

## 3. Запуск

1. **Отключите VPN.** API Ozon не отвечает на зарубежные IP-адреса.
2. Откройте папку проекта (`Documents\GitHub\mp_opiu_excel\Ozon`) в Проводнике.
3. Щёлкните по пустому месту в папке с зажатым **Shift** и выберите **«Открыть окно PowerShell здесь»** (или «Открыть в Терминале»).
4. Выполните:
   ```
   python ozon_finance.py
   ```
5. В окне будет видно, сколько начислений загружено по каждому месяцу. В конце появится строка `Готово: ...xlsx`.
   Файл сохранится в этой же папке, например `ozon_finance_2025-09_2026-09.xlsx`.

Ozon отдаёт начисления **только по одному дню за запрос** (метод `/v1/finance/accrual/by-day`), поэтому за год скрипт делает около 400 запросов на кабинет.
Первый запуск может занять несколько минут. Дни старше недели сохраняются в папку `cache`, и повторные запуски проходят быстро.

## Дополнительные параметры

| Что нужно | Команда |
|---|---|
| Другой период, без правки конфига | `python ozon_finance.py --from 2026-01 --to 2026-08` |
| Своё имя файла | `python ozon_finance.py --out отчёт_август.xlsx` |
| Без листа «Начисления» (файл будет меньше) | `python ozon_finance.py --no-raw` |
| Другой файл с кабинетами | `python ozon_finance.py --config другие_кабинеты.json` |
| Скачать всё заново, без кэша | `python ozon_finance.py --refresh` |
| Сохранить сырой ответ Ozon за один день (для проверки) | `python ozon_finance.py --probe 2026-08-15` |
| Собрать отчёт только из кэша, без API (например, с включённым VPN) | `python ozon_finance.py --from-cache` |

Параметры можно сочетать: `python ozon_finance.py --from 2026-06 --to 2026-08 --no-raw`

Сводный отчёт по всем маркетплейсам собирает `opiu_all.py` — см. [ИНСТРУКЦИЯ_СВОД.md](../ИНСТРУКЦИЯ_СВОД.md).

## Как считаются статьи

- **Выручка** — цена продавца (`sale_amount` в блоке `commission` отправления). Справочно показано, как она сложилась: сколько оплатили покупатели и сколько доплатил Ozon за скидки.
- **Комиссия** — `commission` из того же блока.
- **Остальные статьи** — виды начислений из справочника Ozon (`/v1/finance/accrual/types`): логистика, обратная логистика, эквайринг и платёжные услуги, реклама, хранение, штрафы, подписки, компенсации.
- **Сверка:** сумма статей по каждому начислению равна `total_amount`. На реальных данных за год (47 тыс. начислений) без расшифровки осталось 0 ₽.

## Что в Excel

- **Итого** — отчёт о прибылях и убытках по всем магазинам вместе, по месяцам: выручка, комиссия, логистика, возвраты, эквайринг, реклама, хранение, компенсации, сумма к начислению и доли от выручки.
- **По магазинам** — ключевые показатели каждого магазина рядом.
- **Лист на каждый магазин** — отдельный отчёт, как на листе «Итого».
- **Начисления** — все начисления построчно с фильтрами, для сверки.
- **Виды начислений** — справочник Ozon (`type_id`, название) и группа отчёта, в которую попал каждый вид. Если какая-то статья оказалась не в той группе, смотрите сюда.

## Если что-то не так

| Сообщение | Что делать |
|---|---|
| `Нет соединения с API Ozon` | Отключите VPN или добавьте `api-seller.ozon.ru` в его исключения |
| `obsolete method cannot be used` | Используется старая версия скрипта — обновите `ozon_finance.py` |
| `HTTP 401` / `HTTP 403` | Неверный Client-Id или API-ключ, либо у ключа нет доступа к финансам, либо истёк срок ключа (3 месяца) — перевыпустите его |
| `HTTP 429` | Слишком много запросов. Скрипт сам повторяет попытки; если ошибка не уходит, запустите позже |
| `No module named 'openpyxl'` | Выполните `python -m pip install openpyxl` |
| `JSONDecodeError` | Ошибка в `ozon_accounts.json`: проверьте запятые и кавычки |
| `PermissionError` при сохранении | Закройте Excel-файл с тем же именем и запустите снова |

Если один кабинет не загрузился, отчёт всё равно соберётся по остальным. Названия пропущенных кабинетов будут в конце вывода.

**Безопасность:** в `ozon_accounts.json` API-ключи хранятся открытым текстом. Не пересылайте этот файл.
