# Финансовый отчёт Яндекс Маркета — инструкция

## 1. Подготовка (один раз)

Нужны Python 3.10+ и библиотека openpyxl. На этом компьютере оба уже установлены.
```
python -m pip install openpyxl
```

## 2. Ключ API

1. В кабинете продавца Маркета откройте **Настройки → API и модули → Токены авторизации (Api-Key)**.
2. Создайте токен с доступом **«Финансы и отчётность»**. Подойдёт и «Просмотр всех данных».
   Для остатков в юнит-экономике сводного отчёта нужен ещё доступ к товарам/остаткам — проще всего выбрать «Просмотр всех данных».
3. Скопируйте токен.

## 3. Настройка кабинетов

Скопируйте шаблон `ym_accounts.example.json` в `ym_accounts.json` и откройте его в Блокноте (файл с ключами не попадает в git):

```json
{
  "period": { "from": "2025-09", "to": "2026-09" },
  "accounts": [
    { "name": "ЕвроЗоо ЯМ", "api_key": "ACMA:...", "business_id": null, "campaign_ids": [],
      "interval_seconds": 121, "enabled": true }
  ]
}
```

- **name** — название, так будет называться лист в Excel.
- **api_key** — токен из шага 2.
- **business_id** — ID кабинета. Если оставить `null`, скрипт определит его сам. Указывать нужно, только если один ключ видит несколько кабинетов.
- **campaign_ids** — ID магазинов для выручки. Пустой список означает все магазины кабинета.
- **interval_seconds** — пауза между генерациями отчётов: `121` без подписки, `61` на тарифе «Медиум».
- **period** — первый и последний месяц `ГГГГ-ММ`.

## 4. Запуск

Откройте папку `ОПиУ\YandexMarket`, щёлкните по пустому месту с зажатым **Shift**, выберите **«Открыть окно PowerShell здесь»** и выполните:
```
python ym_finance.py
```

**Сколько это длится.** Маркет не отдаёт данные сразу. Скрипт заказывает отчёт, ждёт, пока тот сформируется, и скачивает архив. Новый отчёт можно заказывать **раз в 2 минуты** (на «Медиуме» — раз в минуту).

Лимит считается на кабинет и отдельно для каждого типа отчёта. За 13 месяцев нужно около 5 отчётов по услугам, по 13 отчётов о реализации на каждый магазин и 1 отчёт по заказам. Для кабинета с 4 магазинами **первый запуск займёт около 2 часов**.

Закрытые месяцы (закончившиеся больше 35 дней назад) сохраняются в папку `cache`, и следующие запуски скачивают только последние месяцы. Если связь оборвётся, просто запустите скрипт ещё раз: скачанное не потеряется.

## Дополнительные параметры

| Что нужно | Команда |
|---|---|
| Другой период | `python ym_finance.py --from 2026-01 --to 2026-08` |
| Собрать Excel из уже скачанного, без запросов к Маркету | `python ym_finance.py --from-cache` |
| Скачать заново даже закрытые месяцы | `python ym_finance.py --refresh` |
| Проверить ключ и формат данных (2 небольших отчёта) | `python ym_finance.py --probe` |
| Своё имя файла | `python ym_finance.py --out отчёт_ЯМ.xlsx` |

## Как считаются статьи

**Как Маркет рассчитывается за скидки.** Покупатель платит цену со скидкой Маркета. Разницу до вашей цены Маркет не переводит деньгами: он начисляет **баллы** на баланс. Этими баллами оплачивается большая часть услуг Маркета (в отчёте по услугам это колонка «Скидка за участие в совместных акциях»). Поэтому в отчёте:
- выручка считается по **вашей цене до скидок Маркета**;
- услуги — по **полной стоимости**: деньги + баллы;
- движение баллов и результат деньгами показаны справочно.

| Статья | Источник |
|---|---|
| Выручка: доставлено | Отчёт по реализации, лист «Доставленные товары»: стоимость с НДС **без учёта скидок** (цена продавца). Месяц — месяц отчёта |
| Возвраты | Отчёт по реализации, лист «Возвращённые товары», по цене продавца, со знаком минус |
| Текущий месяц | Отчёт по реализации появляется только после окончания месяца. Пока его нет, выручка берётся из отчёта по заказам: товары со статусом «Доставлен покупателю» по дате доставки. Без подписки этот отчёт доступен только за последние 90 дней |
| Вознаграждение Маркета | Отчёт по стоимости услуг: размещение товаров, поручение на продажу, вознаграждение за продажу, бронирование |
| Логистика и обработка заказов | доставка покупателю, средняя миля, экспресс, забор, вывоз, обработка заказов, складская обработка |
| Приём и перевод платежей | приём платежа, перевод платежа, поручение на перевод, рассрочка |
| Продвижение и лояльность | бусты, полки, баннеры, рассылки, реклама, программа лояльности и отзывы |
| Хранение и склад | платное хранение, приёмка, излишки, хранение возвратов, маркировка, утилизация |
| Подписки и прочие | подписки, персональный менеджер, расширенный доступ |
| Компенсации | Отчёт по реализации, лист «Утраченные товары»: компенсация минус декомпенсация |

Услуги относятся к месяцу по **дате оказания услуги**. Сумма услуги = оплачено деньгами + оплачено баллами.

**Итого** = выручка − услуги Маркета + компенсации.

**Справочно** (в итоги не входит):
- **Оплачено покупателями деньгами.**
- **Баллы:** начислено за скидки Маркета, списано на услуги и изменение остатка. Обычно почти всё начисленное сразу уходит на оплату услуг.
- **Результат деньгами** = оплаты покупателей − услуги деньгами + компенсации. Он отличается от «Итого» ровно на изменение остатка баллов.
- **Подарочные бонусы** Маркета на продвижение.
- **Невыкупленные товары.**
- **Месяцы, выручка которых взята из отчёта по заказам.**

**Премия** за участие в совместных акциях — это выплата деньгами неизрасходованных баллов. Баллы уже учтены в выручке, поэтому в «Итого» премия не добавляется. Она входит только в результат деньгами.

## Сверка с выплатами (лист «Выплаты»)

Строится по «Отчёту по платежам» Маркета, отчёты кэшируются кусками по 3 месяца.

- **Начислено к выплате деньгами** — платежи покупателей, возвраты, удержания за услуги, компенсации и премии по дате транзакции. Отменённые заказы («Не будет переведён») и баллы («Справочно») не учитываются.
- **Перечислено на счёт** — суммы платёжных поручений по их дате. Внизу листа есть список всех поручений.
- **Не перечислено на конец месяца** — сколько Маркет должен накопительно. Скрипт сверяет эту цифру с суммой транзакций со статусами «Будет переведён» и «Будет удержан». Строка «Расхождение» должна быть 0.
- **Результат деньгами из ОПиУ за предыдущий месяц.** Маркет перечисляет результат месяца частями в течение следующего месяца, поэтому эта строка должна совпадать с «Перечислено на счёт».

Листы **«Услуги»** (деньги / баллы / полная стоимость) и **«Реализация»** (цена продавца / оплачено покупателями) показывают суммы по каждому листу исходных отчётов за месяц. С ними удобно сверяться с кабинетом.

## Если что-то не так

| Сообщение | Что делать |
|---|---|
| `HTTP 401` | Неверный Api-Key |
| `HTTP 403` | У ключа нет доступа «Финансы и отчётность» |
| `лимит запросов Маркета (420)` | Скрипт сам подождёт и повторит |
| `укажите business_id` | Ключ видит несколько кабинетов — впишите нужный ID |
| `генерация не удалась` | Повторите позже. Если ошибка повторяется, сократите период |

**Безопасность:** ключи в `ym_accounts.json` лежат открытым текстом. Не пересылайте этот файл.
