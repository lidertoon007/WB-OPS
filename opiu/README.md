# ОПиУ маркетплейсов — расчёт внутри WB OPS

Скрипты перенесены 22.10.2026 из `Документы\GitHub\mp_opiu_excel` (репозиторий stavtime/mp_opiu_excel,
коммит 35c395d) вместе с исправлением налога от фактической цены покупки. Дальше папка живёт
сама по себе: обновления репозитория сюда автоматически не приходят.

- Собрать отчёт: раздел «Финансы» в WB OPS или `Обновить_отчёт.bat` в этой папке.
- Подробная инструкция: `ИНСТРУКЦИЯ_СВОД.md`.
- Ключи API кабинетов: `Wildberries\wb_accounts.json`, `Ozon\ozon_accounts.json`, `YandexMarket\ym_accounts.json`.
- Себестоимость и подготовка: `cost.csv`; новые артикулы без цены — в `cost_missing.csv`.
- Кэш ответов API: `*\cache\`. Без кэша первая сборка скачает данные заново.
- Проверка налога: `python tests\test_tax_purchase_base.py`.

Ключи, себестоимость, кэш и отчёты в git не попадают (см. `.gitignore` WB OPS).

## Отличия от mp_opiu_excel

- Налог считается от фактической цены покупки (после скидок маркетплейса), см. `tests\test_tax_purchase_base.py`.
- Сборка из кэша (`--from-cache`) тоже идёт до текущего месяца: раньше при `period.to` в конфиге
  раньше текущего месяца последние месяцы отрезались как «вне периода».
