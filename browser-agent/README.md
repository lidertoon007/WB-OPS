# Локальный мост браузерного агента

Запуск:

```powershell
$env:OPENAI_API_KEY="..."
node server.mjs
```

Мост слушает `http://127.0.0.1:8787/agent`. Он получает задачу из расширения, передаёт модели снимок активной страницы и возвращает аналитический ответ. Для подключения реального цикла действий добавьте в `server.mjs` вызов модели с function/tool calling и отправляйте команды `snapshot`, `click`, `scroll`, `open` обратно через endpoint `/execute`.
