# WB OPS Market Research

Chrome Extension (Manifest V3) для быстрой разведки карточек товаров на Wildberries, Ozon и Яндекс.Маркете.

## Установка

1. Откройте `chrome://extensions`.
2. Включите «Режим разработчика».
3. Нажмите «Загрузить распакованное расширение» и выберите папку `chrome-extension`.
4. Откройте карточку товара на поддерживаемом маркетплейсе. В правом нижнем углу появится «Исследование».

Данные сохраняются локально в Chrome. Кнопка «Экспорт CSV» выгружает собранные карточки для анализа в Excel/Google Sheets.
