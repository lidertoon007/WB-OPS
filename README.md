# WB Operations Service

Каркас сервиса для автоматизации отзывов и вопросов Wildberries и отчётности по поставкам FBS.

## Запуск

Первый раз:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -e ".[dev]"
copy .env.example .env   # и вписать WB-токен
```

Дальше — двойной клик по `start_wb_ops.bat` и открыть http://127.0.0.1:8000.
Для разработки: `uvicorn app.main:app --reload`.

Тесты: `python -m pytest` (из корня проекта).

## Разделы панели

Каждый пункт бокового меню открывает свой раздел (без перезагрузки страницы, адрес в браузере меняется):

| Адрес | Раздел |
|---|---|
| `/` | Главная: сводка, входящие, отчёты FBS, жалобы, журнал |
| `/dashboard` | Дашборд «Оцифровка»: прибыль и маржа, заказы, продажи, реклама/ДРР, логистика, выкуп, хранение, комиссия, себестоимость, налоги, капитализация, оборачиваемость — за неделю, месяц или свой период, с фильтрами по бренду, категории и артикулу и сравнением с прошлым периодом (данные WB из кэша ОПиУ; цифры совпадают с «Финансами») |
| `/reviews` | Все отзывы: поиск, фильтры (даты, маркетплейс, кабинет, статус заказа, статус ответа, рейтинг, теги «хвалят/жалуются»), карточки товара с фото, правка и отправка ответа, групповые действия, выгрузка в Excel/CSV; фильтры сохраняются в адресе страницы |
| `/complaints` | Очередь жалоб на отзывы 1–2★: основания (спам, мат, оскорбления, политика, отзыв о доставке/ПВЗ, отзыв о другом товаре), выбор причины WB, текст жалобы, заполнение формы и отправка через отдельный браузер WB с подтверждением |
| `/questions` | Все вопросы: режим ответов (индивидуальные / ИИ / шаблоны), проверка на вопросе |
| `/templates` | Ответы на отзывы: режим (индивидуальные / ИИ / шаблоны), проверка на отзыве, фразы сборщика, базовые и личные шаблоны |
| `/settings` | Автоответы на отзывы и правила |
| `/ai` | Подключение ИИ (Claude или OpenAI-совместимый сервис), подпись, тон и длина ответов |
| `/recommendations` | Рекомендации товаров |
| `/import` | Импорт истории отзывов из WB за период |
| `/products` | Модели и таблицы замеров для ответов на вопросы, база характеристик товаров |
| `/nomenclature` | Товары → «Номенклатура и себестоимость»: все товары (карточки WB, отчёт ОПиУ, остатки и цены WB, `cost.csv`), правка себестоимости и подготовки прямо в таблице, новая цена с месяца, история цен, групповая правка, выгрузка; пишет в `opiu/cost.csv` |
| `/knowledge` | База знаний (обзор, товары, магазин, группы) |
| `/analytics` | Аналитика и отчёты: дашборд по отзывам/вопросам/чатам, способы ответа, тональность, теги, тренды товаров, отчёт по товару (с ИИ-анализом), сохранённые отчёты с выгрузкой в Excel/CSV/PDF |
| `/cabinets` | Кабинеты Wildberries, Ozon, Яндекс.Маркета: ключи, юрлицо, переключатели «Отзывы / Вопросы / Чаты» (загрузка пока только из WB) |
| `/chats` | Чаты с покупателями |
| `/messengers` | Агенты в мессенджерах (в разработке) |
| `/profile` | Учётная запись владельца, режим публикации, резервная копия базы, ссылки на выгрузки и API |
| `/notifications` | Уведомления в Telegram и на email: новые отзывы (можно только 1–3★), ответы, вопросы, чаты, ошибки загрузки; фильтр по кабинетам |
| `/team` | Моя команда: одноразовые ссылки-приглашения, сотрудники, отключение доступа |
| `/finances` | ОПиУ маркетплейсов (расчёт в папке `opiu`): сводка, ОПиУ по месяцам, контроль, товары; пересборка отчёта кнопкой |

## Структура

- `app/main.py` — API (FastAPI) и подключение страниц;
- `app/static/dashboard.html` — разметка, стили и скрипты панели;
- `app/static/router.js` — маршрутизация разделов меню и разделы «Аналитика», «Импорт», «Личный кабинет»;
- `app/static/knowledge.js` — раздел «База знаний»;
- `app/services/review_composer.py` — индивидуальные ответы на отзывы без ИИ (фразы — `app/knowledge/review_phrases.json`, редактируются в «Шаблонах ответов»); `app/services/ai_writer.py` — черновики через ИИ с проверкой и откатом на сборщик; `app/static/replies.js` — интерфейс.
- `app/services/question_composer.py` — индивидуальные ответы на вопросы (размер по таблице замеров, рост, длина, состав, цена…); `app/services/product_models.py` — модели товаров (`app/knowledge/models.json`, редактируются в «Товарах»; WB ID привязываются из `app/knowledge/nm_vendor.json` и прошлых вопросов); `app/static/questions.js` — интерфейс.
- `opiu/` — расчёт ОПиУ по Wildberries, Ozon и Яндекс Маркету (перенесён из mp_opiu_excel, см. `opiu/README.md`); `app/services/finance.py` и `app/static/finance.js` — раздел «Финансы»: показывает последний `opiu/opiu_all_*.xlsx` и запускает `opiu_all.py --no-unit [--from-cache]`.
- `app/services/` — работа с WB API, черновики, публикация, жалобы, отчёты;
- `app/services/analytics.py` и `app/static/analytics.js` — раздел «Аналитика и отчёты» (API `/api/analytics/*`; способ ответа берётся из поля `source` черновика, «вручную» — если отправленный текст отличается от подготовленного);
- `app/services/cabinets.py` — кабинеты; `app/services/team.py` — приглашения и входы сотрудников (хранится только хэш ключа); `app/services/notifier.py` — уведомления Telegram/email; `app/static/settings.js` — разделы кабинетов, уведомлений, команды и учётной записи;
- `app/services/review_list.py` и `app/static/reviews.js` — раздел «Все отзывы» (API `/api/reviews`, `/api/reviews/export`); `app/services/wb_images.py` — фото товаров WB по WB ID (`/api/wb/images`, сервер фото запоминается в базе);
- `app/services/nomenclature.py` и `app/static/products.js` — номенклатура и себестоимость (`/api/nomenclature`); карточки WB кэшируются в `app/knowledge/wb_cards.json`, перед записью `cost.csv` сохраняется `cost.csv.bak`;
- `app/services/dashboard.py` и `app/static/dashboard.js` — дашборд (`/api/dashboard`); дневная выгрузка `wb_finance.py --grain day --from-cache` сохраняется в `opiu/Wildberries/cache/_wbops_dashboard_day.json` и пересобирается сама, когда обновился кэш WB;
- `app/storage.py` — SQLite (`data/wbops.sqlite3`).

## API

Проверки:

- `GET /health` — состояние сервиса;
- `GET /api/fbs-reports` — индекс отчётов поставок FBS в `fbs_reports/`;
- `POST /api/replies/draft` — безопасное формирование черновика ответа.
- `GET /` — веб-панель со сводкой FBS-отчётов и сохранёнными черновиками.
- `POST /api/sync/{cabinet_id}` — получить необработанные вопросы и отзывы WB и создать черновики;
- `GET /api/inbox` — посмотреть сохранённые входящие WB.
- `PUT /api/replies/drafts/{item_id}` — изменить текст черновика;
- `POST /api/replies/publish/{item_id}` — опубликовать после явного отключения `WBOPS_DRY_RUN`.
- `POST /api/replies/drafts/{item_id}/confirm` — явное подтверждение черновика перед публикацией.
- `GET /api/fbs-reports/export` — скачать Excel-сводку по поставкам FBS;
- `GET /api/products/knowledge` и `PUT /api/products/knowledge/{wb_id}` — база характеристик товаров для предметных ответов;
- `GET /api/admin/backup` — скачать резервную копию локальной базы SQLite;
- `POST /api/fbs-reports/upload` — загрузить FBS-файл через веб-интерфейс;
- `PUT /api/fbs-reports/{filename}/status?status=...` — отметить FBS-файл как новый, проверенный, отчитанный или ошибочный;
- `GET/PUT /api/templates/{key}` — управлять рабочими шаблонами ответов;
- `GET/PUT /api/settings/auto-sync` — включить или выключить автоматическую синхронизацию;
- `GET/PUT /api/settings/auto-replies` — настроить автоответы на отзывы: диапазон рейтинга, режим, модерацию и правила по ключевым словам;
- `POST /api/auto-replies/run` — вручную обработать уже загруженные отзывы и создать черновики;
- `GET /api/audit` — журнал синхронизаций, изменений черновиков и публикаций.
- `GET /api/complaints` — очередь кандидатов на жалобу с основанием и чек-листом;
- `PUT /api/complaints/{item_id}` — отметить жалобу как обработанную вручную в ЛК WB.

Для вопросов используется `app/knowledge/questions.json`: точный повторный вопрос по тому же WB ID может получить проверенный исторический ответ, а новые вопросы обрабатываются тематическими шаблонами (размеры, состав, наличие, уход, сезон, цена, детали модели и доставка).

Отчёты поставок FBS нужно складывать в папку `fbs_reports/` (или указать другую папку через `WBOPS_FBS_REPORT_ROOT`). Старые PDF «Отчёт о пострадавших товарах» к поставкам FBS не относятся и сервисом больше не индексируются. Поддерживаются PDF, CSV и XLSX; для точной сверки нужен пример выгрузки FBS с колонками поставки, товара и количества.

Жалобы через WB API отключены самой площадкой (с 8 декабря 2025), поэтому WB OPS подаёт их через отдельное окно Chrome/Edge на компьютере владельца: вход в кабинет WB делается в этом окне один раз (пароли панель не видит), панель находит отзыв, проверяет его ID, заполняет форму и отправляет только после подтверждения. Повторная подача одного отзыва заблокирована. Сервис автоматически классифицирует отзывы 1–2 звезды и готовит консервативную очередь для подачи через личный кабинет. Одна низкая оценка без явного нарушения не считается основанием.

Автопубликация отключена (`WBOPS_DRY_RUN=true` по умолчанию). Подключение WB API и публикация будут добавлены после подтверждения кабинетов, правил ответов и режима согласования.

Автоответы работают в безопасной схеме: синхронизация получает новые отзывы, генератор выбирает персональный шаблон с учётом рейтинга, темы, имени покупателя и статуса покупки, затем сохраняет черновик. До публикации текст проходит проверку и требует подтверждения оператора. Автопубликация доступна только отдельной настройкой и не может быть включена одновременно с обязательной модерацией.

Панель по умолчанию принимает запросы только с локального компьютера. Чтобы пустить сотрудников, запустите `start_wb_ops_team.bat` (слушает локальную сеть) и пригласите их в разделе «Моя команда»: без входа по приглашению сеть получает только страницу `/join`; токены, ключи, финансы, кабинеты, уведомления и команда доступны только владельцу (запросы с 127.0.0.1). Действия сотрудников пишутся в журнал с их именем. Для развёртывания за защищённым reverse proxy можно явно включить `WBOPS_ALLOW_REMOTE=true` и обязательно добавить внешний слой авторизации.
